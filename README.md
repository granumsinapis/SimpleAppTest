## 🚀 How to Run This App

Follow these steps to run the app in Android Studio:

1. Open **Android Studio**.
2. Click on **"Start a new Android Studio project"**.
3. Choose **Empty Activity**, then click **Next**.
4. Set the project name (e.g., `MyApp`) and package name (e.g., `com.example.myapp`).
5. Click **Finish** to create the project.
6. Replace the contents of:

   - `MainActivity.java` (inside `app > java > your.package.name`) with the provided Java code.
   - `activity_main.xml` (inside `app > res > layout`) with the provided XML layout.

7. Connect a device or start an emulator.
8. Click the **Run** ▶️ button in Android Studio.

You should see **"This is my App"** centered on the screen.
